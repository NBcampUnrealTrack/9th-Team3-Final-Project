## 체크아웃과 Unity Build

사용자가 정정한 경로 `D:/Unproject/knight`에서 작업했다. 시작 시 브랜치는 `feat/UI_Change1106`, HEAD는 `dc75edb8`, 작업 트리는 깨끗했다. 첨부 요청에 적힌 main과 달랐지만 현재 체크아웃을 기준으로 진행하고 브랜치를 전환하거나 병합하지 않았다. 적용할 AGENTS.md는 없었다.

엔진 연결은 `5.8`, 설치 엔진은 `D:/Unreal/UE_5.8`의 **5.8.4 / CL 58902052**다. 타깃은 `knightEditor Win64 Development`다.

보고된 충돌은 두 cpp의 익명 네임스페이스에 같은 `bool Save(UObject*)`가 있으면 Unity 번역 단위에서 중복 정의가 되는 문제다. 현재 체크아웃은 이미 정비 진입 커맨드렛에 `SaveEntranceAsset`, 강화 VFX 커맨드렛에 `Save`를 사용한다. 각 호출과 패키지 저장 플래그/반환값 처리를 확인했고 수정하지 않았다. 주변 커맨드렛에도 같은 시그니처의 중복 정의는 없었다.

UI 수정 전에 `-ForceUnity -NoUBTMakefiles`를 사용한 Editor 전체 빌드가 성공했다. 생성된 `Module.knightEditor.cpp`의 37, 41행에 두 실제 cpp가 함께 포함되었으며 해당 번역 단위가 컴파일됐다. Unity를 끄거나 프로젝트 빌드 설정을 변경하지 않았다.

## UI 동작

- 오른쪽 임무/난이도 목록, 선택 스크롤바와 버튼을 제거했다. 지도 마커와 키보드/패드 지도 탐색이 같은 선택 경로를 사용한다. 오른쪽에는 선택된 퀘스트 하나만 표시한다.
- 지역 제목 → 임무 제목/정적인 난이도·탐색 배지 → 클리어 보상/실제 `MoneyReward`의 `1000gold` 형식 → 획득 소재 → 조건부 부위 파괴 보상 → 고정 출격 버튼 순서다. 소재가 많으면 보상 영역 하나만 스크롤된다. 휠로 난이도를 바꾸지 않는다.
- 각 소재의 `Item->Icon`과 `DisplayName`, 독립적인 퀘스트 보상 행의 수량 범위/확률을 그대로 사용한다. 일반 보상은 `ClearRewards`, 부위 파괴 보상은 `PartBreakRewards`다. Raid 보상을 합치거나 보상 데이터를 수정하지 않는다.
- 실제 `RequiredBrokenPart` 태그를 우선하여 머리/가슴/꼬리 파괴 조건을 표시한다. 다른 태그는 원문을 유지한다. 탐색 모드는 금액/소재를 만들지 않고 보상 없음 안내만 표시한다.
- 미지정 아이콘은 중립적인 대시로 표시하고 아이템 및 누락 아이콘 경로를 로그에 남긴다. 원본 아이콘은 ScaleToFit으로 비율을 유지한다.
- 어두운 남색 배경, 파란 절각 테두리와 얇은 구분선은 Slate 기하로 그린다. 참고 이미지에서 그림을 추출하거나 대체 소재 그림을 만들지 않았다. 새 텍스처/스타일 에셋은 없다.
- `출격 가능`, 난이도별 클리어 표시를 지도/패널에서 제거했다. 진행도와 출격 검증은 그대로이며 실제 잠금/미완성 사유만 남긴다. 남부 지하 저장소 및 탐색 마커/해금 규칙은 변경하지 않았다.
- 기존 정보 패널의 0.18초 전환과 전환 중 출격 차단을 유지한다. 마지막 지도 선택이 표시/출격 대상과 일치해야 실행된다.

## 연속 윤곽 효과

기존 `M_UI_StageMap`을 재사용한다. 동일한 불규칙 경계 수식을 256구간으로 적분한 길이 표를 사용해 **3.0초에 한 바퀴** 도는 머리 위치를 계산한다. 프레임 시간으로 진행하며 루프 이음새는 순환 거리로 처리한다. 전체 테두리를 번쩍이지 않고, 정적인 약한 테두리 위로 부드러운 머리와 꼬리만 이동한다.

선택 변경 시 이전 구역의 움직이는 조각은 종료하고 선택 강조는 기존 0.12초로 사라진다. 지도 갱신/호버/드래그는 루프 시각을 초기화하지 않는다. 숨겨진 화면과 선택 없는 상태에서는 애니메이션 시계가 진행하지 않는다. 기존 MID 하나를 재사용한다. 구역 기하, 히트 검사, 마커 좌표, 확대/축소는 변경하지 않았다.
