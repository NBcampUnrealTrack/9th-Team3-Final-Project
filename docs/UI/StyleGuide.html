방향 DIRECTION

UI는 메카 파일럿의 조종석 화면처럼 느껴지게 해요. 화면 대부분은 연한 파랑과 흰색의 얇은 선과 글자로 차분하게 깔고, 시선이 가야 하는 곳에만 주황색을 써요. 포커스, 선택, 락온, 과열, 경고가 여기에 해당해요.

폰트 TYPOGRAPHY · IBM Plex Sans KR

IBM Plex Sans KR 하나로 통일해요. 한글과 영문, 숫자가 모두 들어 있어서 Composite Font로 묶을 필요가 없어요. SIL OFL 라이선스라 상업 게임에 넣어 배포할 수 있어요. 이 페이지도 이 폰트로 렌더링되고 있어요.

Light 300 · SemiBold 600 · Bold 700
세이브 1 · 이어하기 · RAID START · 12:48

굵기 차이로 위계를 만들어요. 큰 영문 제목은 Light + 넓은 자간, 버튼과 이름은 SemiBold예요.

Caption · 13 · Medium[Esc] 뒤로 [Enter] 확인
⚠ 숫자는 고정폭으로타이머처럼 계속 바뀌는 숫자는 글자 폭이 달라서 좌우로 흔들려요. 숫자 전용 텍스트 스타일(TS_Knight_Number)의 Font 설정에서 Force Monospaced를 켜고 Monospaced Width를 0.6 근처로 맞추세요. 모든 글자에 적용되니 숫자 전용 스타일에만 켜요.

크기는 UMG 폰트 크기 기준 초안이에요. 본문은 14 아래로 내리지 않아요. 실제 1080p 화면에서 한 번 띄워보고 조정하세요.

형태 언어 SHAPE

모서리는 45° 컷

둥근 모서리 대신 대각선으로 잘라요. 패널은 두 곳(좌하, 우상)만 잘라서 방향성을 줘요. 이 페이지의 패널이 그 예시예요.

선은 1px, 바탕은 반투명

테두리는 Frost Dim 1px이에요. HUD 패널은 Navy 900에 알파 80%로 깔아서 뒤의 3D 장면이 비쳐 보이게 해요.

포커스는 주황 대괄호 [ ]

Hover나 선택 시 양옆에 주황 브래킷이 펼쳐져요. 락온 박스도 같은 귀퉁이 모양이라 메뉴와 HUD가 하나로 이어져요.

패널은 9-slice

AI로 만든 패널 이미지는 Image Brush의 Draw As: Box + Margin으로 써요. 그래야 크기를 바꿔도 모서리가 늘어나지 않아요.

UI 사운드 SOUND

진행 계획임시 합성음 8종이 /Game/Knight/UI/Sounds에 SoundWave로 들어가 있어요. 최종 AI 생성음(라이선스 확인 후)은 같은 이름의 WAV로 Reimport하면 참조가 그대로 유지돼요. 임시음은 Tools/UI/make_temp_ui_sounds.py로 다시 만들 수 있어요. Hover의 피치 랜덤은 필요하면 Sound Cue(Modulator)를 에디터에서 만들어 감싸요.

⚠ 락온 이름표는 몬스터를 따라다녀요박스 위치는 ViewModel에 없어요. 위젯이 매 프레임 락온 대상의 월드 위치를 Project World Location to Screen으로 화면 좌표로 바꿔서 옮겨야 해요. 대상이 화면 오른쪽 끝에 가까우면 가지선을 왼쪽으로 뒤집고, 이름표는 세이프존 밖으로 나가지 않게 고정하세요. 락온 대상은 knightTargetLockComponent에서 가져와요.

BossStatus 슬롯은 알파에서 비워둬요. ViewModel은 그대로 살아 있어서, 나중에 HP 바를 보여주기로 하면 위젯만 추가하면 돼요.

AI 시안 프롬프트 AI PROMPT · v0.2

⚠ AI 이미지에는 글자를 넣지 마세요AI가 그린 글자는 깨지고 번역도 안 돼요. 패널, 프레임, 아이콘, 배경만 이미지로 뽑고 텍스트는 전부 UMG에서 얹어요. 패널은 9-slice로 쓸 수 있게 단색 배경 위에 한 장씩 따로 요청하세요.

마지막 줄의 대괄호 안에서 하나씩 골라 요소별로 뽑아요. 한 번에 시트 전체를 뽑으면 톤은 맞지만 잘라 쓰기 어려워요. 락온 가지선은 위젯에서 선으로 그리는 게 더 깔끔해서, AI로는 귀퉁이 마커 모양 참고용으로만 뽑아도 충분해요.

10/8 확정 체크 DECISIONS

  1. 이름·톤: Project Knight, 메카 파일럿 HUD 느낌 (확정)
  2. 색: 연한 파랑 + 흰색 베이스, 시선 집중은 주황 (확정)
  3. 폰트: IBM Plex Sans KR 단일 (확정)
  4. 보스 HP: 숨김, 락온 이름표로 이름만 표시 (확정)
  5. AI 시안 1차: 패널, 버튼 프레임, HP 바 프레임 세 가지를 뽑고 톤 고정
  6. 임시 사운드: 합성음 8종 임포트 완료 → 최종은 AI 생성음으로 Reimport 교체
