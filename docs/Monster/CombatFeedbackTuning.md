# 전투 피드백 튜닝 탭 (Combat Feedback Tuning)

PIE 중에 히트스톱, 카메라 셰이크, 경직, 넉백, 그로기, 카메라 FOV 같은 전투 피드백 수치를 바꿔 보고, 같은 공격(몬스터 공격이나 플레이어 공격)을 버튼 하나로 다시 실행해 비교한 뒤 마음에 드는 값을 에셋에 저장하는 에디터 도구. `knightMonsterAnimDebug` 플러그인의 에디터 모듈에 있어서 패키징 빌드에는 들어가지 않는다.

- 열기: 레벨 에디터 **Tools > Knight > Combat Feedback Tuning**, 또는 콘솔 `knight.FeedbackTuning.Open`
- PIE 중에만 동작한다. 탭이 열려 있으면 PIE를 시작하고 1.5초 뒤 값을 자동으로 읽는다. 무기를 바꾼 뒤처럼 어빌리티가 바뀌면 **다시 읽기**를 누른다.

---

## 1. 쓰는 순서

1. PIE 시작(값은 자동으로 읽힌다). 대상 몬스터는 Gameplay Debugger로 고른 몬스터, 없으면 플레이어에게 가장 가까운 몬스터다.
2. **AI 정지**를 켜고 비교할 공격을 고른다.
   - 몬스터 공격: 첫 줄 **공격 선택** → **다시 실행**. **실행 전 배치**가 켜져 있으면 플레이어를 몬스터 정면(기본 900cm)에 세운 뒤 공격한다. **반복**을 켜면 공격이 끝나고 간격(초)만큼 쉬었다가 계속 다시 실행한다.
   - 플레이어 공격: 둘째 줄 **플레이어 공격 선택** → **플레이어 공격**. 히트스톱 값이 있는 플레이어 어빌리티(1~4타, 강공격, 반격 등)가 목록에 나온다. **실행 전 배치**가 켜져 있으면 몬스터 몸통에 닿는 거리(캡슐 반지름 + 150cm)에 세우고, 착지한 뒤 공격한다.
3. 공격을 실행해 지금 느낌을 본다.
4. 찾기 칸에 `Slam HitStop`처럼 낱말을 넣어 값을 좁히고, 숫자를 바꾼다. 바뀐 값은 다음 타격부터 바로 적용된다. **몬스터 / 플레이어 / 카메라** 체크로 묶음을 골라 볼 수 있다.
5. 마음에 들면 **저장**. 아니면 **되돌리기**나 줄마다 **원래대로**.

보조 옵션:
- **플레이어 체력 고정**(기본 켬): 맞아도 체력을 바로 채운다. 피격 반응과 히트스톱은 그대로 나온다(무적과 다름).
- **몬스터 체력 고정**: 몬스터가 죽지 않게 한다.
- **배속**: 월드 배속. 히트스톱처럼 짧은 연출을 느리게 볼 때 쓴다.

## 2. 어떤 값이 보이나

값은 세 묶음으로 나뉜다. 같은 원본은 먼저 찾은 묶음에 들어간다(몬스터 공격이 쓰는 셰이크는 몬스터 쪽).

| 묶음 | 찾는 곳 | 저장 |
|---|---|---|
| [몬스터] | 몬스터의 어빌리티, 컴포넌트, 데이터 에셋, 거기서 참조하는 몽타주 노티파이(GroundImpact 등)와 카메라 셰이크 | 됨 |
| [카메라] | 카메라 반응 표(`DA_CameraImpact`), 플레이어 카메라 매니저(피격 셰이크, 넉다운 프레이밍)와 지금 재생 중인 셰이크, 플레이어 카메라 컴포넌트(스윙 FOV·킥)와 그 카메라 모드·가림·페이드 처리기, 카메라 모디파이어(어둠, 귀먹음, 포효 충격파) 클래스 기본값 | `DA_CameraImpact`만 됨 |
| [플레이어] | 플레이어의 어빌리티(공격 히트스톱 등), 컴포넌트, 노티파이 | 잠금 |

카메라 모디파이어는 공격 중에만 생기는 것도 있어서 PIE 인스턴스가 아니라 클래스 기본값을 보여 준다. 바꾸면 다음에 생기는 모디파이어부터 적용된다.

몬스터·플레이어 묶음에서 고르는 기준:

- 이름에 설정의 키워드가 들어간 값만 보인다(HitStop, Shake, Knockback, SlowMo, Poise, Groggy, Flinch, Stagger, Push, TimeDilation, ForceFeedback, Dust, Splash, Parried).
- 감싼 구조체나 객체 이름이 키워드에 걸리면 그 안의 숫자는 모두 보인다. 예: `FlinchImpact.*`, `HitFlinch.*`, `GuardPush` 컴포넌트, `GA_*_BreakFlinch`.
- 카메라 셰이크 패턴과 카메라 묶음은 이름과 상관없이 게임 클래스가 선언한 숫자를 모두 보인다.
- 엔진 클래스가 선언한 값(이동 컴포넌트의 PushForceFactor 등)은 뺀다.

키워드, 카메라 클래스, 배치 거리, 플레이어 공격 간격은 **Project Settings > Knight > Monster Anim Debug > Feedback Tuning**에서 바꾼다.

몽타주 노티파이는 `AM_Janyeol_SlamBoth › Ground Impact @1.17s`처럼 몽타주 이름과 시각으로 구분한다. 같은 공용 에셋(셰이크 등)은 그걸 쓰는 모든 공격에 같이 적용된다.

## 3. 저장과 되돌림

- 값을 바꾸면 원본(어빌리티 Blueprint 기본값, 컴포넌트 템플릿, 데이터 에셋, 몽타주 노티파이)과 PIE에 이미 만들어진 복사본에 같이 쓴다. 어빌리티는 몬스터가 생길 때 인스턴스를 미리 만들어 두므로 복사본까지 바꿔야 바로 반영된다.
- **저장**은 바뀐 **몬스터 쪽** 값의 에셋만 저장한다.
- **플레이어 묶음**과, 카메라 묶음 중 플레이어 담당 에셋(`/Game/Knight/Blueprints/`, `/Game/Knight/Abilities/`, `/Game/Knight/Camera/CM_`, 설정의 `FeedbackLockedPathPrefixes`)은 바꿔 보기만 되고 저장은 잠겨 있다. **바뀐 값 복사**로 `[묶음] 출처 · 경로: 전 → 후` 목록을 복사해 담당자에게 넘긴다. 설정의 `bFeedbackAllowSavingPlayerValues`로 풀 수 있다.
- C++ 기본값만 있는 값(`/Script/` 패키지, 제목에 "C++ 기본값")은 저장할 수 없다. 카메라 매니저와 카메라 모디파이어가 여기에 해당한다. 복사한 값을 헤더 기본값으로 옮긴다.
- **저장하지 않은 값은 PIE가 끝날 때 원래대로 돌아간다.** 에디터에 열린 에셋이 몰래 바뀐 채로 남지 않게 하기 위해서다.

## 4. 카메라 반응 (DA_CameraImpact)

전투 순간마다 셰이크와 별개로 **시야각 펀치, 캐릭터 쪽으로 당기기, 화면 기준 이동, 타격 방향 밀림, 색 갈라짐**을 잠깐 걸었다가 돌려놓는다. 카메라 매니저(`AknightPlayerCameraManager`)가 보고 있는 플레이어의 전투 이벤트를 듣고 재생하므로 플레이어 코드는 바뀌지 않는다.

| 순간 | 신호 | 세기 |
|---|---|---|
| `PlayerHit` | 플레이어가 근접 피해를 줌 | 그로기 피해 |
| `PlayerHeavyHit` | 위와 같고 세기가 `MinStrength` 이상이면 `PlayerHit` 대신 | 그로기 피해 |
| `Damaged` | `Event.Damaged`(가드·패링 직후 0.2초 안의 피해는 무시) | 피해량 |
| `PoiseBroken` | `Event.PoiseBroken` | 그로기 피해 |
| `Guarded` / `Parried` / `GuardBroken` | `Event.Guarded` / `Event.ParrySucceeded` / `Event.GuardBroken` | 1 |
| `MonsterImpact` | `MonsterImpactShake`(`CS_Monster_GroundImpact`) 셰이크가 시작됨 | 셰이크 세기 |

항목마다 값:
- `MinStrength` / `FullStrength` / `MinScale`: 세기가 MinStrength 아래면 하지 않고, FullStrength에서 100%, MinStrength에서 MinScale.
- `FOVPunch`: 좁힐 시야각(도). 음수면 넓힌다. 사용자 시야각 설정 뒤에 적용돼 넓은 시야에서도 보인다.
- `PullIn` / `PullPivotHeight`: 카메라~캐릭터 거리의 몇 %를 캐릭터(위치 + 높이) 쪽으로 당길지. 강공격에서 등 뒤로 확 다가오는 연출.
- `ShoulderOffset`: 화면 기준 오른쪽(X)·위(Y) 이동(cm). 당기기와 같이 쓰면 어깨 너머 구도.
- `Push`: 타격 방향 밀림(cm). 때릴 때는 타깃 쪽, 맞거나 막을 때는 때린 쪽 반대로.
- `ChromaticAberration`: 화면 가장자리 색 갈라짐(0~5).
- `AttackTime` / `HoldTime` / `ReleaseTime`: 올라감 → 머묾 → 돌아옴(실제 시간). `Cooldown`: 같은 반응 최소 간격.

기본값 기준: 강공격 3~4단(그로기 피해 32 이상)부터 `PlayerHeavyHit`(당기기 35%, FOV 5도), 반격·내려찍기(60 이상)는 최대. 모든 움직임과 색 갈라짐은 사용자의 화면 흔들림 설정을 따른다(0이면 꺼짐).

탭에서 쓰는 법:
1. 셋째 줄 **카메라 반응**에서 순간을 고르면 찾기 칸이 그 순간 값만 보이게 채워진다.
2. **미리보기**로 공격 없이 최대 세기로 재생한다. 값을 바꾸고 다시 누르면 바로 비교된다.
3. 실제 공격과 같이 보려면 **플레이어 공격**(강공격 4단 등)이나 몬스터 공격을 실행한다.
4. **저장**하면 `DA_CameraImpact`에 남는다.

켜기·끄기(`bEnabled`)는 탭에 숫자로 나오지 않는다. 끄려면 에셋에서 체크를 풀거나 `MinStrength`를 크게 둔다.

## 5. 콘솔 명령

탭과 같은 데이터를 쓴다. 찾을 낱말은 공백으로 여러 개 줄 수 있고, 모두 들어간 값만 고른다.

| 명령 | 설명 |
|---|---|
| `knight.FeedbackTuning.Open` | 탭을 연다 |
| `knight.FeedbackTuning.List [낱말…\|-refresh]` | 값 목록. PIE 복사본 수와 원본과 다른 복사본 수도 같이 적는다. 낱말에 `[카메라]`처럼 묶음 이름도 쓸 수 있다 |
| `knight.FeedbackTuning.Set <낱말…> <값>` | 고른 값을 모두 바꾼다. 예: `knight.FeedbackTuning.Set GA_Janyeol_SlamBoth HitStopDuration 0.15` |
| `knight.FeedbackTuning.Save` | 바뀐 몬스터 값을 저장한다 |
| `knight.FeedbackTuning.Revert` | 저장하지 않은 값을 되돌린다 |
| `knight.FeedbackTuning.Impact [순간]` | 카메라 반응을 최대 세기로 미리보기한다. 순간이 없으면 목록을 보인다 |
| `knight.FeedbackTuning.PlayerAttack [이름] [배치=1]` | 플레이어 공격을 실행한다. 이름이 없으면 목록을 보인다. 막히면 막은 태그를 로그에 적는다 |

공격 실행, 반복, AI 정지, 배속은 `knight.AnimDebug.*`(Gameplay Debugger와 같은 기능)를 같이 쓴다.

## 6. 주의

- 값을 실행 중에 한 번만 읽어 두는 코드(BeginPlay에서 복사 등)는 바꿔도 다음 PIE부터 반영된다. 바로 반영되지 않으면 이 경우를 의심한다.
- 여러 공격이 같이 쓰는 몽타주·셰이크는 한 곳에서 바꿔도 모두 바뀐다.
- 플레이어 공격 강제 실행은 2~4타처럼 앞 단계 콤보 태그(`Combo.*`)가 필요한 공격에 그 태그를 실행 순간에만 잠깐 붙인다. 달리기 공격처럼 다른 조건이 있는 공격은 막히고, 로그에 막은 태그를 적는다.
- 플레이어는 몬스터 정면의 바닥에 바로 세운다. 그 자리가 몬스터 몸(턱 등)과 겹치면 50cm씩 물러나 빈자리를 찾는다.
- 저장은 에셋 파일을 바로 덮어쓴다. 다른 사람이 같은 에셋을 작업 중이면 먼저 맞춘다.
